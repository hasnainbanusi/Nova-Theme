# NOVA — Ecommerce Frontend

A polished, responsive ecommerce storefront built with vanilla HTML, CSS and JavaScript.

## Features
- Responsive desktop/tablet/mobile layout
- Product categories and filtering
- Functional shopping cart with localStorage
- Search overlay
- Newsletter interaction
- Mobile navigation
- Marketplace-ready frontend structure
- No framework required

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Next conversion targets
This frontend can be converted into:
- WordPress theme (PHP + WordPress APIs)
- Shopify theme (Liquid)
- Other template marketplace formats

## Important
Product imagery is represented with CSS artwork in this demo. Replace these blocks with licensed product photography before marketplace submission.
